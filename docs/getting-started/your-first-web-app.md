# Your First Web App

This tutorial walks you through building a web API with Hardened and ASP.NET Core. You will create a simple greeting service with a controller, dependency injection, and a test.

**What you will build:**

- A `GET /hello/{name}` endpoint that returns a personalized greeting
- A service registered via compile-time DI
- A test using `ITestWebApp`

**Time:** ~10 minutes

---

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) or later
- [NuGet configured for GitHub Packages](nuget-setup.md)

---

## Step 1: Create the project

```bash
dotnet new web -n HelloHardened
cd HelloHardened
```

Add the Hardened ASP.NET Core packages:

```bash
dotnet add package Hardened.Web.AspNetCore.Runtime --prerelease
dotnet add package Hardened.Web.SourceGenerator --prerelease
dotnet add package Hardened.DependencyModules.SourceGenerator --prerelease
```

`Hardened.Web.AspNetCore.Runtime` brings the core framework and ASP.NET Core bridge (it
transitively pulls in `Hardened.Requests.Abstract`, `Hardened.Requests.Runtime`, and
`Hardened.Web.Runtime`). The two source generators emit the routing and DI wiring at
build time.

---

## Step 2: Create the Application module

Create `Application.cs` in the project root. This is your **composition root** -- the `[HardenedModule]` attribute tells the source generator to discover and wire up all services, controllers, and configuration in this assembly.

```csharp title="Application.cs"
using Hardened.Shared.Runtime.Attributes;

[HardenedModule]
[AspNetCoreRuntime.Module]
public partial class Application
{
    public static WebApplicationBuilder CreateBuilder(string[] args)
    {
        var hardenedApp = new Application();
        var environment = new EnvironmentImpl(arguments: args);

        var builder = WebApplication.CreateBuilder(args);
        builder.Services.AddTransient<IHardenedEnvironment>(_ => environment);
        hardenedApp.ConfigureModule(environment, builder.Services);

        return builder;
    }
}
```

!!! note
    The class **must** be `partial`. The source generator emits the `ConfigureModule` method and all DI wiring into the other partial.

---

## Step 3: Update Program.cs

Replace the contents of `Program.cs`:

```csharp title="Program.cs"
var builder = Application.CreateBuilder(args);
var app = builder.Build();

app.UseHardened();
app.Run();
```

`UseHardened()` is an extension method generated by the ASP.NET Core source generator. It registers the Hardened request pipeline as middleware.

---

## Step 4: Create a controller

Create a `Controllers/` directory and add `HelloController.cs`:

```csharp title="Controllers/HelloController.cs"
using Hardened.Web.Runtime.Attributes;

public class HelloController
{
    [Get("/hello/{name}")]
    public string Hello(string name)
    {
        return $"Hello, {name}!";
    }
}
```

That is all you need. No base class, no `[ApiController]`, no `AddControllers()` call. The source generator:

1. Discovers the `[Get]` attribute at compile time
2. Generates route registration code
3. Binds the `name` path parameter automatically

---

## Step 5: Add a service with DI

Create a `Services/` directory with an interface and implementation:

```csharp title="Services/IGreetingService.cs"
public interface IGreetingService
{
    string Greet(string name);
}
```

```csharp title="Services/GreetingService.cs"
using Hardened.Shared.Runtime.Attributes;

[Expose]
public class GreetingService : IGreetingService
{
    public string Greet(string name)
    {
        return $"Hello, {name}! Welcome to Hardened.";
    }
}
```

The `[Expose]` attribute registers `GreetingService` as the implementation of `IGreetingService` in the DI container. The default lifetime is **transient**. Use `[Singleton]` or `[Scoped]` if you need a different lifetime.

Now inject the service into the controller:

```csharp title="Controllers/HelloController.cs"
using Hardened.Web.Runtime.Attributes;

public class HelloController
{
    private readonly IGreetingService _greetingService;

    public HelloController(IGreetingService greetingService)
    {
        _greetingService = greetingService;
    }

    [Get("/hello/{name}")]
    public string Hello(string name)
    {
        return _greetingService.Greet(name);
    }
}
```

## Step 6: Run the app

```bash
dotnet run
```

Open your browser or use curl:

```bash
curl http://localhost:5000/hello/World
```

You should see:

```
Hello, World! Welcome to Hardened.
```

## Step 7: Add tests

Create a test project alongside your web project:

```bash
cd ..
dotnet new xunit -n HelloHardened.Tests
cd HelloHardened.Tests
dotnet add reference ../HelloHardened/HelloHardened.csproj
dotnet add package Hardened.Web.Testing --prerelease
```

### Bootstrap file

Create `Bootstrap.cs` to configure the test framework:

```csharp title="Bootstrap.cs"
using Hardened.Web.Testing;
using Hardened.Shared.Runtime.Attributes;

[assembly: WebTesting]
[assembly: HardenedTestEntryPoint(typeof(Application))]
```

`HardenedTestEntryPoint` tells the test framework to use your `Application` module as the composition root, giving tests access to the full DI container and request pipeline.

### Write a test

```csharp title="HelloControllerTests.cs"
using Hardened.Shared.Runtime.Attributes;
using Hardened.Web.Testing;

public class HelloControllerTests
{
    [HardenedTest]
    public async Task Hello_ReturnsGreeting(ITestWebApp testWebApp)
    {
        var response = await testWebApp.Get("/hello/World");

        response.Assert.Ok();

        var body = response.Deserialize<string>();
        Assert.Equal("Hello, World! Welcome to Hardened.", body);
    }
}
```

!!! tip
    `[HardenedTest]` extends xUnit's `[Fact]` attribute. The test framework automatically injects `ITestWebApp` and any other registered services into your test method parameters.

Run the tests:

```bash
dotnet test
```

---

## What just happened?

At compile time, the Hardened source generators:

1. Scanned your assembly for `[Get]`, `[Post]`, `[Put]`, `[Delete]` attributes and generated route registrations
2. Found `[Expose]` on `GreetingService` and generated DI registration code
3. Wired up the `Application` partial class with a `ConfigureModule` method that registers everything
4. Generated `UseHardened()` to plug into the ASP.NET Core middleware pipeline

No reflection. No runtime scanning. Everything is resolved at build time.
